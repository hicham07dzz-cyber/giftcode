# NEON RIFT — صدع النيون

A mobile-first Arabic arcade runner built with plain HTML, CSS and JavaScript.

## Play
Open `game/index.html` in a browser, or enable GitHub Pages for this repository and visit `/game/`.

## Included
- 12 themed worlds with progressive speed and difficulty.
- Three-lane runner gameplay, jump, obstacles and collectible energy shards.
- Touch/swipe controls plus keyboard support.
- Synthesized sound effects using Web Audio (no external API keys or paid assets).
- Level unlocks and best score saved locally in the browser.
- Responsive intro, level picker, pause and result screens.
- Original SVG logo.

## Controls
- Swipe left/right or use the arrow buttons to change lanes.
- Swipe up or tap **قفز** to jump over barriers.
- Collect 12 energy shards to clear a world.

## Notes
Progress is stored in the current browser using localStorage. Audio starts after the first user interaction, as required by mobile browsers.
